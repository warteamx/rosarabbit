# hexo-theme-warteamx

WarteamX brand theme for the [Rosa Rabbit](https://rosarabbit.com) Hexo blog.
Built on top of [hexo-theme-landscape](https://github.com/hexojs/hexo-theme-landscape) with full WarteamX brand styling applied.

## Features

- 🌑 **Dark mode by default** — deep dark gradient canvas with frosted-glass cards
- ☀️ **Light mode toggle** — crisp cool gradient, persisted via `localStorage`
- ⚡ **Neon accents** — Electric Blue `#7ECFFF` and Fuchsia `#F102CE`
- 🎞️ **Micro-animations** — hover lifts, nav underlines, page fade-in, image scale
- 🎨 **CSS custom properties** — all brand tokens via `:root` and `[data-theme="light"]`
- 📱 **Responsive** — adapts from desktop to mobile

## Usage

Set `theme: warteamx` in your Hexo `_config.yml`.
